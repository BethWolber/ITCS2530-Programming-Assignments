Cross stitching is a form of embroidery that uses exclusively x shaped stitches. It is very easy for beginners to start since each stitch is exactly the same. It can become quite time consuming if the stitcher is working on a large project, but it is also very relaxing. Patterns can range from very simple to incredibly complex, as seen below.
